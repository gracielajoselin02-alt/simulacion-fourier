# Simulación y análisis de señales con la Transformada de Fourier

## Descripción
Este proyecto genera tres señales elementales: un pulso rectangular, una función escalón y una señal senoidal. Utiliza Python para representar las señales en el dominio del tiempo y analizar sus espectros de frecuencia mediante la Transformada de Fourier.

## Herramientas utilizadas
- Python
- NumPy
- Matplotlib

## Funcionamiento
El programa genera las tres señales, calcula la Transformada de Fourier mediante la función `np.fft.fft()` y muestra gráficas del dominio del tiempo, la magnitud y la fase del espectro.

## Cómo ejecutar el programa
1. Instalar Python.
2. Instalar las librerías con el comando `pip install numpy matplotlib`.
3. Ejecutar el archivo `simulacion_fourier.py`.

## Objetivo
Comprender la representación de las señales en los dominios del tiempo y la frecuencia, así como la utilidad de la Transformada de Fourier en el análisis de señales.
